# AlgoFlow

Interactive algorithm lessons with animations and AI explanations.

## Setup

```bash
npm install
npm run dev
```

## Environment Variables

- `OPENAI_API_KEY` – for real AI.
- `MOCK_AI` – set to `1` to use deterministic mock responses.

## Scripts

- `npm run dev` – start dev server
- `npm run build` – build for production
- `npm run lint` – ESLint
- `npm run format` – Prettier
- `npm test` – run Vitest
